# О вики

**База знаний** — открытая вики для инструкций, справочных материалов и полезных наблюдений на любые темы.

## Как устроены материалы

Статьи можно читать без регистрации. Для предложения правок нужен аккаунт GitHub. Изменения публикуются после проверки владельцем; история версий позволяет увидеть, что и когда менялось.

Первые статьи показывают возможный формат. Каталог будет развиваться вместе с материалами — общей темой вики не ограничивается.

## Принципы

- **Понятность:** объяснять существенные условия и термины.
- **Проверяемость:** указывать источники и отделять факты от предположений.
- **Актуальность:** обозначать дату для сведений, которые меняются.
- **Участие:** исправления и дополнения приветствуются.
